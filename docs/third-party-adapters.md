# 充电与狐友来源适配

这两个来源独立于学校教务、OA、报修和个人课程；保持匿名、按请求读取。学校账号、Cookie 或 WebVPN 不用于这些第三方接口。来源字段在解析边界校验，不能进入业务层后才被随意转换为文本或空列表。通用依赖方向和改版步骤见[来源维护](source-adapters.md)，本文只维护两来源的专属契约。

## 模块职责

| 层 | 充电 `features/charging/` | 狐友 `features/huyou/` |
| --- | --- | --- |
| `schema.py` | 固定主机/路径、主脚本文件规则、协议和状态枚举 | 固定公开 API、请求限额和客户端协议常量 |
| `parser.py` | HTML 入口、公开 JS 配置、JSON 信封、设备协议和插座 | 输入与响应身份/文本/类型、分页、帖子、评论和内嵌回复 |
| `adapter.py` | 匿名 HTTP、签名、大小/时间/请求预算、原有有界配置更新 | 匿名 HTTP、签名、大小/时间/请求预算、原有有界重试 |
| `service.py` | 设备选择、缓存租约、采集失败与聚合结果 | 多关键词搜索、主评论与楼中楼的读取编排及部分失败 |
| 其他 | `models.py` 保留只在内存使用且不显示值的公开配置；已有 `charging_cache.py` / `charging_devices.py` 保留快照和目录政策 | `cache.py` 为纯合并、检索和展示函数，不启动网络，不读 Store |

旧 `charging.py` 保留 `ChargingClient` / `ChargingService`、签名和插座解析入口，门面显式传入原客户端/设备注入点与配置缓存。旧 `huyou.py` 保留客户端、原函数/常量导出及共享时间模块；功能包不反向依赖兼容门面。Store 所依赖的狐友缓存辅助函数没有引入 Store/App 反向导入。

## 充电契约

首页脚本仍只接受同站 HTTPS 的 `static/js/index.<hash>.js`，允许包装、无关属性、相对地址和同一入口重复出现；不同有效候选、歧义 `src` 或未知入口明确报 `schema_changed`。不会跟随候选去任意站点或猜备用路径。

公开签名配置只从可识别的对象直接字段中读取唯一 `app_id` / `app_secret`。普通未知属性可保留，字符串或注释里的示例不是配置，不能把不同对象的字段拼在一起。不执行 JS；动态计算、可能覆盖配置的展开/计算属性或冲突配置明确停止。配置值仅在进程内使用，不进入结果、日志或仓库。

JSON 信封的业务码必须为整数，不能把字符串或布尔当成功。成功必须有 `data`；其后设备类型、协议与端口各自校验。权限/限流码优先于错误消息，避免冲突的“设备离线”文字掩盖平台拒绝。设备离线、未知类型、结构变化和真正空闲分别表示，不制造零空闲结果。

原插座编号、状态检查与未知正整数状态处理保留；未观测插座仍计入未知。六小时内存配置缓存、最多一次已识别签名/时间错误触发的配置更新、固定读取方法、18 次请求/40 秒预算、每页最多四台和已有冷却政策保持。失败保留上次成功数据及原时间；TTL、跨进程设备租约和旧租约不能覆盖新结果的政策不变。

## 狐友契约与部分失败

身份、正文、标志和分页类型在纯解析层检查。明确成员卡、删除、隐藏与异常结构分别处理；文本字段变成对象或数组不能静默变为空正文，缺失的正文也不能证明已读到一份完整的新全文。正常昵称、帖子 URL、稳定 ID、图片链接上限和非官方标记保持。

每页先完成结构/身份校验再合并，重复身份、坏分页或游标明确失败。缺失/异常的回复数量、内嵌回复容器或列表不能证明楼中楼完整；主评论范围和全部讨论是否完整分别核对。数量或分页矛盾不授权清理未读缓存。

某个关键词、后续评论页或某条楼中楼失败时，保留已读的正常内容和错误范围，继续仍可读取的独立部分；原平台级登录要求、限流及预算停止条件继续适用。旧正文、讨论和采集时间在未得到可替换的完整新范围时保留。完整空讨论与未能读到讨论不混用。

不加入新接口、凭据、浏览器登录、后台采集、模型调用或额外重试；匿名 Cookie 清理、固定来源、响应大小及原请求/时间预算仍由访问层执行。

## 剩余重构顺序

| 范围 | 后续工作边界 |
| --- | --- |
| `yuketang_readiness` | 独立的只读作业诊断；以后可拆题目纯解析、固定 API、字体读取和离线渲染，保留答案字段排除与字体/网络隔离；当前未进入 MCP 主查询链 |
| `auth` / `webvpn` | 单独审查登录证明的字段契约与 DOM。MySTU 验证需补缺失/字符串布尔的合成样本，再确定登录证明语义；不直接把完整课程 schema 绑到认证探针。保留凭据、会话代次、人工挑战和冷却保护 |
| 对分易后台 | 是独立用户启动的监听/提交流程；协议调整应在后台与本地控制接口的边界处理，不能随普通只读来源重构一起改提交行为 |
| 学期课表自动取数 | 本地文件生成已有独立核心和技能；学校全学期来源仍待取证，不把已有个人日程冒充完整课表；见[当前能力与后续条件](timetable.md) |

具体迁移、合成测试、安装及兼容比对结果保留在[来源分层验证](verification/2026-10-20-adapters.md)，不以这些结果更新历史真实读取日期。实际来源证据见[充电协议](charging-platform.md)和[狐友查询](huyou.md)。
