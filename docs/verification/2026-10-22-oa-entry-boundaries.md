# OA 能读什么、什么条件下能读：2026-10-22 补充

**现有 MCP 可以读取 OA 通知。** 原站及目标内容允许匿名访问时不需要学校登录；原站读取受限时，再判断是否需要 WebVPN 访问通道。配置引导围绕读取能力、范围和访问条件展开。

## 当前能力

| 想读的内容 | 当前工具与范围 | 限制 |
| --- | --- | --- |
| 最近通知列表 | `refresh_source(source="oa", limit=20)`；标题、发布部门、日期、原文链接 | 每次读取列表首页，数量参数 1–50；不是全部历史公告 |
| 按关键词找通知 | `search_notices(source="oa", query="…")` | 搜索本地已采集缓存；需要最新消息时先刷新，翻缓存页不等于抓学校历史页 |
| 通知正文与附件列表 | `get_notice(item_id, refresh=true)` | 从已缓存通知的学校链接读取；是否能读取决于该条内容及保存的访问路径 |
| 附件文字 | `read_attachment(item_id, index=0)` | 先取得附件列表；支持可提取文字的 PDF/文本，单次最多 8 MiB、PDF 最多 100 页；扫描 PDF 不做 OCR，图片、Word、Excel 等其他格式不承诺提取 |

## 什么条件下能读

| 当前条件 | MCP 应如何处理 | 可给出的结论 |
| --- | --- | --- |
| 运行 MCP 的主机能连接 OA 原站，目标列表/正文/附件允许匿名访问 | 直接匿名读取，不要求先登录 | 可以读本次实际返回的内容 |
| 原站列表直读失败，但主机能访问 WebVPN，已有或可完成其认证，且 OA 路由可用 | 当前列表采集实现尝试 WebVPN 路径；正文和附件仍分别核实 | 只有实际内容读取成功，才说明该内容能通过此路径读取；门户登录成功不够 |
| WebVPN 未登录、已过期或需要本人确认挑战 | 按当前错误提示完成该通道所需认证；各阶段有界处理 | 尚不能承诺目标通知可读；不能把通道认证当作获得所有内容权限 |
| 两条路径都不可达，目标内容拒绝访问，或页面已变化无法解析 | 报告具体网络、权限或解析错误，保留旧缓存的时间及范围 | 本轮未能读取；不解释成没有通知或学校停服 |

所有条件均以 **MCP 运行主机**为准。Chrome 能访问不保证服务器也能访问；浏览器 URL 不能证明其是否经过代理/TUN。代码忽略环境代理也不能证明绕过系统路由，不自动修改 DNS、代理、hosts 或证书设置。

当前实现的换路范围需说准确：列表先匿名，遇到 `AppError` 才尝试 WebVPN；正文和附件按已缓存的 HTTP 原站或 HTTPS WebVPN 来源路径读取，没有每篇失败后自动切换路径的通用兜底。

## 记录边界

`features/notices/service.py` 先匿名采集、失败后才调用 WebVPN；`adapter.py` 的原站列表及 HTTP 正文读取不使用保存的 WebVPN 会话。`sources.py` 的 `oa.session="webvpn"` 描述已有 WebVPN 路径的状态归属，不能解释成查询 OA 必须登录。

本补充只调整文档及原 CSV 的 OA 关系说明，原普查的 661 行、254 项探测结果与时间保持不变。未修改工具接口、业务代码、访问白名单或网络设置；本轮没有员工登录、凭据读取或业务写入。

本次验证：现有通知服务与解析测试 70 项通过，Ruff、文档本地链接及差异检查通过；逐行对比确认 CSV 仅修改 OA 的分类说明，原有探测列、URL、行数和时间均保留。
