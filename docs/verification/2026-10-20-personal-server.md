## 行为与故障检查

- 一个 SDK HTTP 实例接受两个客户端，共享同一报修草稿；删除一个会话不关闭其他会话/草稿，实例退出才清理资源。
- 默认回环监听，私密 Bearer 文件必填；错误/重复鉴权、Host/Origin、查询参数、超大请求被拒绝且不回显原内容。
  外部入口域名和默认端口规范化后使用精确白名单，无通配绕过。
- 主密钥和 HTTP 令牌独立，拒绝把 Fernet 主密钥（同文件或副本）误作 Bearer。
  外置主密钥仅显式启用，两个应用使用独立加密凭据映射；坏密文不覆盖，跨进程短事务串行。
- 初始化只接受全新目录；第二文件写入失败会撤销本轮文件与空目录，不递归清理、不覆盖已有密钥。
  路径检查与后端一致，涵盖数据目录边界、链接/重解析及文件权限。
- 无显示环境在启动浏览器或下载前明确失败；登录及报修继续使用有界面浏览器、原登录证明和提交守卫。
  模拟 Playwright 的测试显式绕过交互门禁，真实环境策略测试不全局伪造 DISPLAY。
- 设置页支持固定端口；Windows 独占绑定、重复绑定失败后首实例可用、释放后重新绑定均通过。
  线程启动失败的清理不等待不存在的服务线程。
- 网络诊断始终标明检查发生在 MCP 宿主；仅改实例标签时缓存证据/时间不变，不把远程握手等同校园网可达。
- 容器模板通过 YAML/端口/挂载检查、Git Bash shell 语法及合成入口运行。
  忽略 TERM 的合成子进程在有界宽限后被清理，独立进程保留；没有关闭实际用户服务。

## 尚未验收

当前机器没有 Docker，尚未实际构建镜像、启动 noVNC 或通过虚拟桌面完成学校登录。
本轮未新跑 Linux/macOS CI、Tailscale/SSH 跨机连接、真实学校读取/提交或真实远程客户端。
这些需要在目标服务器上分别验收，不能沿用旧学校业务成功作为本次证据。

实现的是单用户私有 Bearer HTTP，不包括公开 OAuth、多租户、自动账号/后端迁移或跨机文件下载。
使用和后续验证步骤见[服务器说明](../server.md)与[容器说明](../server-container.md)。
