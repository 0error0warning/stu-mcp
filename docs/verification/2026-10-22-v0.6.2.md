# v0.6.2 匿名限流回退与公开安装复核

v0.6.1 公开后的独立安装检查遇到 GitHub 匿名 REST API 限流：实际响应为 HTTP 403，
`x-ratelimit-remaining=0`。该版本正确报告检查失败，但共享公网出口下无法继续查询；
没有把失败当作已是最新版。v0.6.1 的标签和发行附件保留原样。

## 实现与测试

v0.6.2 只在明确的 `403 + remaining=0` 或 429 时回退固定官方 Atom 发行源。
UTF-8、Atom 命名空间、官方仓库和规范版本标签均受校验，拒绝 DTD/实体声明，不读取正文中的指令。
回退先核对固定 SHA256SUMS 中唯一 wheel 引用；安装仍验证实际 SHA-256 和包元数据。
没有复用 gh 凭据、增加 token 配置、切换代理或改写系统网络。

新增 17 项限流和 feed 边界用例；更新专项共 **98 passed**。
普通 403/401/500、坏 XML、外部地址、错误路径、正文假链接、坏 manifest 和错误包仍停止。
`metadata_source=github_atom`、`prerelease=null`、`asset_list_verified=false` 如实区分 API 和订阅证据。

## 真实只读与独立安装

同一网络下匿名 REST API 仍 403 时，官方 `releases.atom` 实际返回 200。
源码 CLI 成功回退并读取当时已发布的 0.6.1；候选 0.6.2 不降级。

把候选 0.6.2 wheel 安装到临时 uv tool 环境，没有使用锁定依赖约束，
实际 CLI `update --check` 与 SDK stdio 的 `check_updates`、`update_self` 均成功。
安装归属自动识别为 `uv_tool`，运行/安装版本为 0.6.2；当时最新发行是 0.6.1，所以升级调用只读返回无需降级。
测试使用独立数据目录和已有公共发行信息，未修改用户真实安装、学校凭据或发起学校业务请求。

## 发行范围

既有 47 项工具的输入/输出 schema 和注解未改；0.6.1 的安装器、进程锁与报修保护继续使用。
跨平台完整回归、隔离安装及各系统五种入口升级由本版 GitHub Checks 验证，结果链接见公开发行说明。
公开附件校验和发布后的实际工具回读在发行收尾完成；历史学校业务验收不因本次更新测试扩展。
