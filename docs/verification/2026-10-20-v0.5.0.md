# v0.5.0 学生预览版发布准备

本节记录开源 STU MCP 的本地发行验证。最终标签、跨平台 CI、发行附件和下载校验以 [v0.5.0 发行页](https://github.com/0error0warning/stu-mcp/releases/tag/v0.5.0) 的实际结果为准；历史真实学校读取及未验收范围继续保留在[验证索引](../verification.md)和[发行说明](../releases/v0.5.0.md)。

## 版本与兼容

`pyproject.toml`、包内 `__version__` 和 `uv.lock` 均为 `0.5.0`，锁文件只更新本项目版本，依赖版本未变。README、安装与升级步骤、功能文档和技能标签同步；默认安装链接固定到本次 wheel。

当前共 38 项 MCP 工具，较 v0.4.1 的 19 项新增充电 2 项、对分易 8 项、报修 7 项和网络诊断 2 项。发布收尾没有改变整理后的 38 项完整定义；既有参数、描述、schema 和注解逐项比对一致。课表技能不增加 MCP 工具，也不新增学校完整课表读取接口。

## 本地检查

Windows / Python 3.12.13：`uv run --locked --extra dev pytest -q` 为 **1489 项通过、2 项符号链接权限检查跳过**，用时 151.17 秒。Ruff 与 `git diff --check` 通过，原有链接及片段检查通过。全部测试使用合成数据和临时环境，不以这些检查更新学校真实业务核查日期。

0.5.0 wheel 和 sdist 构建成功。候选 wheel 在隔离 `uv tool` 环境中验证功能包、兼容入口、网页/后台资源、8 种 stdio 配置导出的实际启动与工具发现，以及 2 种原 Skill/CLI 和课表技能命令执行。课表资源完整解压后以 `-I -S` 生成合成 CSV/ICS；对分易后台与回环网页可用，关闭 MCP 后后台继续运行，测试结束正常退出。

## 升级与范围

升级保留用户数据和其他客户端配置，重新运行当前客户端的 `connect ... --apply` 并重载。正在运行的旧对分易后台需本人暂停并退出，再打开新版。技能按客户端支持方式安装或重新导出；资源包的本机 Python 路径不充当跨机器运行配置。

本轮未访问学校个人数据、提交报修、新课堂签到或写入远端日历，也未替换用户正在使用的 MCP/Hermes 私有服务。报修原生 MCP 的真实提交、新课堂自动签到、完整学期课表自动取数和各日历 App 实际导入仍按已有验收边界报告。
