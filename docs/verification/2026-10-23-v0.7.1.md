本批为开源 stu-mcp，Hermes 私有 School Hub 不在部署范围。实读发生于 2026-10-24 UTC，用户所在芝加哥仍为 10 月 23 日晚。理论课表另见[原验收](2026-10-23-academic-timetable.md)，不改写原时点。

## 正式一卡通适配器

使用当前 `auth_http.smartcard` / `login_http`，以独立学工号查询密码、同一临时 cookie jar 的正常图片验证码完成 HTTP 认证。页面用固定 JS 字面量指定登录 action；适配器识别该合同，不执行 JS。登录后按明确学工号标签精确核对本人，再保存独立加密会话，不保存查询密码或验证码。

严格解析最初识别出三处与合成假设不同的结构，修正后补齐回归：余额栏含三种带标签金额；全部类别名为“查询全部”；分页汇总在结果表最后一行，含“当前第…页”。初次失败没有报告成余额为零或无流水，也未重发结果未知的密码请求。

读取均为 `cached=false`、`transport=school_http`，复用独立会话，不起浏览器。回执只保存字段存在性、计数、时点与范围，不保存本人页面、身份、金额、cookie 或密码；临时验证码图已删除。这里的 MCP 是当前源码服务器对象，不表示旧版客户端或私有 School Hub 已更新。

密码 HTTP 例外仅限固定一卡通登录 POST，其业务只读路线只有概况与历史；普通学校密码、TOTP 仍为 HTTPS。未改代理、DNS 或证书校验。最多八个有界查询步骤、三次来源明确的一秒续行，底层跳转还受共享 HTTP 上限约束；不调用挂失、充值、改密、图统计等写入或未接入业务。

多页只读第一页并标记部分范围；多卡账户明确拒绝猜选。多页、其他账号、自然会话过期和更多类别没有由本轮单账号实读一概证明。终端显示、私密网页、取消和代次屏障用合成测试另验。

## 发行门禁

原 48 个工具完整定义逐项保持一致，只追加两项一卡通工具；相对 v0.7.0 的 47 项，加课表共 50 项。默认安装包包含 HTTP、终端验证码和设置页所需组件，不包含 Playwright。Pillow 只用于受限的本地验证码解码／终端显示，不引入 OCR 或模型调用。

本地首轮完整测试为2455通过、4跳过、1失败；失败为能力目录测试固定要求旧7来源，已改成明确保留原来源并加入独立一卡通，定点通过。认证40项、读取82项和设置页交互用例均通过；随后重新运行完整测试。新增隔离 HTTP 诊断仅返回固定错误类别及本脚本行号，禁止输出异常文本、令牌或子输出。

`uv build` 生成0.7.1 wheel及sdist。`check_installed_runtime.py` 的完整隔离安装复核通过：私密设置页、50项 HTTP 契约、各客户端真实 stdio 启动、签到后台生命周期、Skill导出及同一课表核心。首次隔离 HTTP 子检查未给出具体失败点；增加脱敏定位后，同候选完整复核成功，没有据此改业务认证判据或放宽超时。`check_update_runtime.py` 的五种离线升级启动方式通过，保留 Python、extras、配置和用户数据。

最终发行要求 [Checks 工作流](https://github.com/0error0warning/stu-mcp/actions/workflows/checks.yml) 的 Linux Python 3.11／3.13、Windows、macOS 和默认 Docker 五项成功。发行页记录最终提交、全量结果及附件校验值；本记录不把合成测试当作更多学校账号或实际日历 App 导入证明。
