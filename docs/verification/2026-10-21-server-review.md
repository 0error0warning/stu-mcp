# 认证基线与服务器改造复核 · 2026-10-21

本轮继续在 `codex/remote-hosting`，审查此前五个本地服务器提交，并对照 v0.5.0 `3d0afda0f47485409c7cfb09d74a30db541fc2ee` 的工具基线。
未修改 Hermes 私有 `school_hub`、原 School Hub 仓库、生产服务或学校业务数据；未推送、发版或部署。
版本号、main 与已发布 tag 不变，下列结果属于开发分支，不能作为 v0.5.0 发行包已包含这些能力的证据。

## 梳理与修正

完整调用链、各来源的认证方式、状态归属、成功证明及已知薄弱点见[认证基线](../authentication.md)。
此次保留 HTTP、单用户 HostRuntime、外置密钥后端和宿主网络作用域；修正认证入口与默认部署：

- 对分易沿用原微信 OAuth 回调和固定 `P.aspx` 交换，新增本人 TTY 隐藏输入，不接入官网二维码／SignalR。
  CLI 先校验，再复用同一个后台，至多发送一次 `/api/connect`，不调用选课或 start，不创建新计划。
  后台原课程选择回显、同账号已授权持续计划恢复、注销和普通 MCP 退出语义保持。
- CLI 的 `unknown` 指未获得可信后台回执。后台明确失败、上游失败回滚与旧会话保留不冒充本次成功；
  不能从回执丢失推导回滚，也不自动重发一次性回调。
- WebVPN 终端配置调用原 `WebVPNConfig`，输入、存储和配置分别负责，不在配置时执行登录或绑定令牌。
  无头重登仍限受保护 OA 按需读取；补识别可见 `randCode`，在填写及提交前检查，人工挑战暂停。
- Windows WMI 后台继承 `STU_MCP_KEY_FILE` / `STU_MCP_HOME` 路径配置，不传递密钥内容或其他秘密环境值。
- 能力与隐私状态区分人工浏览器、回调及已有无头重登；选定文件后端不再被描述为系统 keyring。
  后端选择、显示变量及已存会话不等于实际健康或真实账号验证。
- 删除默认 VNC/noVNC、Xvfb 服务、桌面密码、窗口管理器、设置页桥接及 shell 多进程监督。
  容器入口为 tini + MCP，保留无头 Chromium 的系统依赖；只发布回环 8765，密钥仍在数据卷之外只读挂载。

第一次完整测试为 1634 passed、4 skipped、1 failed：新增能力枚举中的 `password` 单词触发原隐私断言，
并非返回实际密码。调整为 `headless_totp`，相关 11 项通过；最终完整回归已纳入随后补充的测试并全部通过。
Skill 校验初次因独立脚本缺 PyYAML、随后因 Windows 默认 GBK 解码失败；临时提供依赖并以 UTF-8 重跑通过，未改项目依赖或系统编码。

隔离安装使用真实 SDK 连接实际回环 CLI 服务，发现 38 项工具，核对宿主范围、认证路线、存储后端；
被动状态读取不启动对分易 worker。安装后的两项凭据输入命令在非 TTY 直接拒绝。
原 8 种 stdio 配置命令、3 种技能命令、完整课表资源与合成 CSV/ICS、独立签到后台和 MCP 退出后存活检查仍通过。

终端取消和坏密钥不会替换原配置；临时文件后端实际验证加密保存、旧 WebVPN 会话失效及仅清旧 OA，
status 不读取凭据，remove 沿用原行为保留当前会话。输出和磁盘断言检查合成秘密不明文出现。
对分易测试包含真实回环 LocalServer、合成 Controller／平台响应，覆盖单次请求、旧会话并存、回执中断、原恢复与不新建计划。
WebVPN 挑战测试使用离线 Chromium 和合成页面，不访问学校、不提交真实凭据。

三项独立复核分别覆盖回调/终端、WebVPN/认证边界、部署/文档。
文档按源码收窄了未知回执、后台回滚和课程默认回显的承诺；未把研究到的其他登录入口当作既有能力。

## 未验收与后续问题

- 当前机器没有 Docker；只检查模板与本机 headless 合成页面，没有实际 build/run 镜像。
- 未进行真实微信登录、真实 WebVPN TOTP 续登、学校业务提交或 Tailscale/SSH 跨机验收；本轮未新跑 Linux/macOS CI。
- 教务、MySTU、雨课堂首次登录和报修仍是原人工浏览器流程，基础容器没有为这些流程提供全 CLI 认证。
- 原 MySTU proof 允许缺少正证据的 200 对象、对分易旧失效通知存在认证切换竞态，均列入认证基线；未猜学校字段或改 vendor 来掩盖。
- 私有 Bearer 不等于公开 OAuth／多租户，MCP 连接成功不等于服务器能访问校园内网。
