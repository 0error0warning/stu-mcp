## 安全修复

新增请求范围的日志回归，覆盖 CLI → 本机控制后台 → 对分易交换的一次性 code；认证头、Cookie 和回调不进入库 DEBUG，其他请求日志仍可见。

旧后台把配置代理视为关闭 HTTPS 校验的理由，WSS 也曾硬编码跳过校验。本次保留代理字段，强制 HTTPS/WSS 证书及主机名校验，旧关闭值归一为开启，并移除全局证书告警抑制；本地改动记录在 vendor NOTICE。8 项回归包含真实本机 CONNECT 隧道：受信测试 CA 与正确主机名正常返回；不受信 CA 或主机名不匹配时，在 HTTP 回调 code 发出前以 SSLError 停止。只使用临时合成证书，不改系统信任库、DNS 或代理。
