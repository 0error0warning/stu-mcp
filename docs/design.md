# 设置页设计

## 定位

STU MCP 是给用户自己的 agent 用的本地 MCP。安装和接入由 agent 按安装 prompt 执行 `stu-mcp connect`。当前开发分支的认证默认由本人宿主终端执行纯 HTTP 登录。设置页提供状态、对应 CLI 指引、传输兼容和可选 WebVPN 自动重登配置，不是必需的认证门户。

其余都不放在页面上：

- **接入客户端**由 agent 运行 `stu-mcp connect CLIENT --apply`；客户端列表、配置导出和技能包都在 CLI。
- **刷新**由 agent 通过 `refresh_source` 按需调用，用户不需要理解缓存。
- **学院 / 专业 / 兴趣**由 agent 通过 `set_student_profile` 在对话中记录。
- **公开网站和匿名 OA** 不需要任何配置，不占一行。

## 交互

- 每个账号一行：图标、名称、一行状态、一个按钮。状态只有「未登录 / 已登录 / 已过期 / 等待登录」几种，用颜色和文字区分，不显示内部状态码。
- 默认「登录」显示固定的宿主 CLI 命令，不在后台线程请求 TTY 输入。显式浏览器兼容才显示窗口等待状态；不会自动回退或为服务器启动桌面。
- 教务 HTTP 回调兼容与 OA HTTP 8118 兼容分别说明并由本人明确启用，默认关闭，不互相借用许可；成绩和考试从 HTTPS 发起，密码及动态码始终只发 HTTPS。
- WebVPN 点「设置」原地展开：填学号、密码、动态口令密钥后保存，仅在受保护读取需要时纯 HTTP 重登；也可显式选择可选浏览器兼容。已配置时只显示「更新账号 / 断开」，断开需要二次确认。凭据不回填，提交、失败、离开页面时都清空。
- 操作反馈用底部轻提示，错误停留更久并使用 `role=alert`。

## 视觉

- 单列，最大宽度 560px，居中；浅灰背景上的白色圆角分组卡片，接近系统设置。
- 系统字体；正文 16px，辅助文字不小于 14px；不使用小字角标、编号、大写标签或说明性小字堆叠。
- 一个强调色（青绿），服务图标用各自的纯色底和统一线性图标。
- 自动跟随系统深色模式。
- 只用本地 HTML、CSS、JS 和内联 SVG，遵守既有 CSP；没有字体、图片或追踪请求。

对分易采用相同的单列分组样式，使用独立页面提供微信登录、课程多选、时长、启停和近期结果。登录步骤仅在展开登录面板时显示，状态与 MCP 读取同一后台；使用与进程约定见 [对分易后台](checkin.md)。
