# 设置页设计

## 定位

STU MCP 是给用户自己的 agent 用的本地 MCP。安装和接入由 agent 按安装 prompt 执行 `stu-mcp connect`。设置页只做 agent 做不了、又必须由本人完成的一件事：登录学校账号（教务、MySTU、雨课堂、WebVPN）。

其余都不放在页面上：

- **接入客户端**由 agent 运行 `stu-mcp connect CLIENT --apply`；客户端列表、配置导出和技能包都在 CLI。
- **刷新**由 agent 通过 `refresh_source` 按需调用，用户不需要理解缓存。
- **学院 / 专业 / 兴趣**由 agent 通过 `set_student_profile` 在对话中记录。
- **公开网站和匿名 OA** 不需要任何配置，不占一行。

## 交互

- 每个账号一行：图标、名称、一行状态、一个按钮。状态只有「未登录 / 已登录 / 已过期 / 等待登录」几种，用颜色和文字区分，不显示内部状态码。
- 「登录」直接打开学校页面，页面实时显示等待状态，完成后自动更新；不需要手动刷新页面。
- 教务首次登录时，原地展开一句话说明成绩接口只能走 HTTP，用户点「继续登录」即视为同意。没有单独的高级设置开关。
- WebVPN 点「设置」原地展开：填学号、密码、动态口令密钥后保存，会话过期自动重登；也可改用浏览器登录。已配置时只显示「更新账号 / 断开」，断开需要二次确认。凭据不回填，提交、失败、离开页面时都清空。
- 操作反馈用底部轻提示，错误停留更久并使用 `role=alert`。

## 视觉

- 单列，最大宽度 560px，居中；浅灰背景上的白色圆角分组卡片，接近系统设置。
- 系统字体；正文 16px，辅助文字不小于 14px；不使用小字角标、编号、大写标签或说明性小字堆叠。
- 一个强调色（青绿），服务图标用各自的纯色底和统一线性图标。
- 自动跟随系统深色模式。
- 只用本地 HTML、CSS、JS 和内联 SVG，遵守既有 CSP；没有字体、图片或追踪请求。
