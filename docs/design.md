# 设置页设计

## 定位

STU MCP 给用户自己的 agent 提供本机 stdio 或个人服务器私有 HTTP 接入。本机安装和接入由 agent 按安装 prompt 执行 `stu-mcp connect`。当前未发布源码让本人选择完整 CLI 或自己的浏览器完成配置；两者直接调用同一 HTTP 认证核心。v0.6.2 发行包仍是原 CLI 指引页，区别及验证见[认证说明](authentication.md)和[本轮记录](verification/2026-10-23-private-setup.md)。

其余都不放在页面上：

- **接入客户端**由 agent 运行 `stu-mcp connect CLIENT --apply`；客户端列表、配置导出和技能包都在 CLI。
- **刷新**由 agent 通过 `refresh_source` 按需调用，用户不需要理解缓存。
- **学院 / 专业 / 兴趣**由 agent 通过 `set_student_profile` 在对话中记录。
- **公开网站和匿名 OA** 不需要任何配置，不占一行。

## 交互

- 学校统一账号、雨课堂、对分易、WebVPN 各一行：名称、能用的功能、配置状态和按钮。功能和汇总状态取自能力目录；完成后显示「已配置」，仅未完成项目展示原因，不把本地配置当作当前学校网站可读的证明。
- 只保留一个当前登录工作区。学校账号输入一次，连接全部已接入业务；不再让用户选择教务、MySTU、报修，也不另设单业务会话管理。内部保留独立认证和存储，部分失败保留已完成结果。
- 本机 `open_setup` 自动打开本人的浏览器，私密地址和输入不通过 MCP。CLI 始终完整可用，页面中的命令帮助是可选项，不要求安装 Skill；无桌面服务器可直接使用 CLI。
- 教务已验证的官方旧版回调由适配器内部处理，页面不展示 HTTP 票据复选框；只允许固定教务路线，不改持久传输选项。CLI 原有参数仍兼容，OA 传输选择独立，详见[认证说明](authentication.md)。
- WebVPN 主表单提供账号、密码和可选令牌密钥。填写密钥后安全保存并自动生成动态码验证登录；已配置且启用时直接复用，禁用或暂停时回到主表单更新，没有密钥的手动登录输入当前动态码。普通学校密码不持久保存。凭据不回填，提交、失败、取消、离开页面时清空输入。
- 删除「单独管理与更多设置」及网页旧浏览器任务分支。CLI 保留一个可选帮助入口，功能范围和未接入项折叠展示；不为内部兼容代码保留重复操作面板。
- 状态轮询只在任务运行时进行，失败有有限重试；响应丢失时读取状态，不重复发送输入或回调。取消清除待处理输入，不撤销已完成的会话或原有已授权监听计划。
- 操作反馈用底部轻提示，错误停留更久并使用 `role=alert`。

## 视觉

- 单列，最大宽度 720px，居中；浅灰背景上的一个白色圆角列表，登录工作区不再嵌套卡片。
- 系统字体，正文 16px；保持说明简短，详细功能和未接入服务折叠展示。
- 一个强调色（青绿），配置图标用纯色底和单字标记。
- 自动跟随系统深色模式。
- 只用本地 HTML、CSS、JS；官方二维码在本机生成为 SVG 数据图，遵守 CSP，没有外部字体、图片或追踪请求。浏览器只请求私密回环 API，学校协议由共用核心处理。

对分易采用相同的单列分组样式，使用独立页面提供微信登录、课程多选、时长、启停和近期结果。登录步骤仅在展开登录面板时显示，状态与 MCP 读取同一后台；使用与进程约定见 [对分易后台](checkin.md)。
