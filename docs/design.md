# 设置页设计

视觉主张：本地设置是一张可以快速完成的工作台。浅色纸面、深绿文字和一个绿色强调色，用清晰的行与分隔线呈现状态，不使用卡片墙。

内容顺序：品牌与本机属性 → agent 接入 → 各来源的功能、登录与缓存状态 → 可选学院和兴趣 → 本地存储说明。

狐友来源显示“无需账号”和“由 agent 按关键词搜索”，不显示登录或无关键词刷新按钮；搜索与内容阅读沿用 MCP / CLI，不另建社区浏览界面。

交互主张：先接入，再按需登录。公开工具直接刷新；私有来源默认打开学校页面。WebVPN 自动重登放在折叠的可选区，用户本人填写并明确勾选后启用；凭据不回填，提交后清空输入，不给 agent 展示密码或密钥。操作立即显示反馈、禁用重复操作，登录完成后更新状态。手机布局将状态和操作移到功能名称下方，保留键盘焦点与文字状态。

实现仅使用系统字体、本地 CSS/JS。没有远程追踪、分析 SDK 或外部字体请求。
