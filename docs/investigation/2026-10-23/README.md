## 访问与认证结论

学校统一账号可以作为配置入口，但不能把业务会话合并。一网通办事项目录可匿名读，部分专题要求登录；xg 不同上下文也不能凭同域名共享成功结论。校园卡查询密码、微信/二维码授权、图书馆读者身份、医学院门户和主校 CAS 必须分别验证。

`repair.stu.edu.cn` 的宿舍报修与 `r.stu.edu.cn` 校园服务台分别维护；`booking` 目录、ehall 预约、classroom 教室预约、ELC MRBS 也不是一个接口。医学院图书馆公开读者链接本轮仍指向主校 OPAC，不能因 `med` 域名就虚构独立馆藏后台。

本机调用忽略环境代理并校验证书；没有调整 Clash、DNS、hosts、TUN、证书或无线连接。连接配置名 `stu.edu.cn` 是本机观察，不能当作物理位置或校外可用性证明。名称解析失败、证书过期/缺少签发链、连接超时分别记录，不宣布学校系统永久停用。远端 Firecrawl 只读取公开学校页面，不携带本人凭据或会话，其成功不代表本机可连接。

本轮用户再次明确授权使用此前提供的学校账号，临时 HTTP 调查进程只在内存中保留各业务独立会话，结束后释放；没有保存或导出密码、Cookie、认证票据和令牌。浏览器研究标签已关闭。既有正式教务会话本轮读取失败，未重新认证，也未用旧成功记录冒充本轮成功。
