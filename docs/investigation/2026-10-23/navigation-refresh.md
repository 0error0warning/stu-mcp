# 当前校园导航分类与原 620 URL 的差异核查

本报告补足“只看导航首页”的范围限制。**12 个校园、教学和论文资源分类页全部返回 200；
加入首页明确学校域名链接及学校快速通道正文后，得到 543 个不同 URL。它们与原 620 条
相比有 277 个精确字符串差异，不能解释为 277 个新系统。**

只做公开入口与已完成协议调查的对照；本轮没有接入 MCP，没有认证、预约、申请或其他业务写入。
导航标签只证明该站现在发布了这个引用，不能证明被引用系统仍有效、已经迁移或具有接口。

## 时间与访问方法

- 本机匿名 HTTP，`httpx`、`trust_env=False`、正常 TLS 验证；不修改代理、DNS、证书或 hosts。
- 首次首页核查 `2026-10-23T16:23:51.418526Z`；分类批次为
  `2026-10-23T16:26:12.328964Z` 至 `2026-10-23T16:26:42.035915Z`。
  北京时间分别为 10 月 24 日 00:23:51、00:26:12–00:26:42。
- 三个旧 IP 引用的补查请求时间为 `2026-10-23T16:33:02.125085Z` 至
  `2026-10-23T16:33:09.126524Z`（北京时间 10 月 24 日 00:33:02–00:33:09）；均短连接超时。
  这些是请求开始/核查记录时间，没有把之后的本地 CSV 归并时间冒充联网时间。
- 实际额外读取了导航站自身的 38 个通用分类页：初版选区取到了包含通用分类的父容器。
  已通过本地证据重投影，将其排除出以下统计；没有继续读取这些分类的外部目标。
  整轮含预检查、HTTP 到同站 HTTPS 的跳转及三个 IP 补查，共 108 次 GET；其中分类批次
  `observations.jsonl` 为 102 次。分类范围以以下 12 页为准，不用多读的页面抬高覆盖率。

## 精确差异与词法等价分别计算

基线是 [原目录](../../verification/2026-10-22-campus-entries.csv) 中 620 个 `published_link`
URL，与 [entry-coverage.csv](entry-coverage.csv) 的 620 个 URL 对齐。
保留当前实际发布的协议、主机、路径、query 和 fragment；没有把 HTTP/HTTPS、不同路径或不同
参数默认为同一个可用入口。

只有空 path 与 `/` 的拼写差异另列 `root_slash_only`。fragment 的差异另列，不作为额外服务器
接口；HTTP 请求不会发送 `#` 后的片段，但不能据此保证客户端展示/路由相同。

| 互斥差异类别 | 数量 | 对业务覆盖的含义 |
| --- | ---: | --- |
| 与原目录精确相同 | 266 | 当前仍发布这些精确 URL |
| 仅根路径末尾 `/` 拼写不同 | 169 | 168 个学校域名、1 个外部引用；不是新增业务 |
| 仅导航片段差异 | 1 | 省车辆管理链接 `#carTask`；不是新增服务端接口 |
| 已知学校域名的新路径 | 1 | 新版财务入口；本轮之前的协议报告已覆盖 |
| 旧裸 IP 内容引用 | 3 | 本轮原样短 GET 均连接超时，不能确定现行功能 |
| 外部公开媒体引用 | 77 | 微博墙等；没有扩展为学校业务或登录调查 |
| 其他外部参考 URL | 26 | 25 个基线未列主机，1 个已知主机的协议差异；不算已核实学校业务 |
| **合计** | **543** | **277 个精确差异 = 169 + 1 + 1 + 3 + 77 + 26** |

完整差异保留在 [navigation-new-entries.csv](navigation-new-entries.csv)，每行一个 URL，
`difference_class` 为 URL 对比结果，`comparison_urls` 只填可核对的原始词法对应项；
`primary_disposition` 为互斥用途归类。来源页和原 URL 保留，标签是本轮提取时合并的公开别名，
不是各保留来源逐页的一一配对。`verification_boundary` 区分“仅发现引用”和三个实际 GET。

这些差异不能用来断言学校在今天新增了功能；可能来自旧目录范围、拼写、引用协议和外部链接。
本次也没有逐页重新读取旧目录的 153 篇图书馆资源指南，不能把原目录中未被这 12 类再次引用
的条目一概判成移除或失效。

## 唯一校域路径差异已在协议报告中

官网当前发布的[新版财务入口](https://wpay.stu.edu.cn/api/logcas/checkTicket)与基线
`https://wpay.stu.edu.cn/login` 路径不同。此前
[other-business.md](other-business.md) 和
[administration-completion.md](administration-completion.md) 已分别实测该路径到同站
`/logCas` 再到 SPA，并分析匿名认证入口限制。本次导航刷新只复核它仍被官网发布，没有重复
调用财务业务 API，也没有据此声称个人财务已可读取。

因此，这轮导航差异**没有增加未调查的 `stu.edu.cn` 业务主机或路径**；不等于现有财务、
各业务认证、个人接口或第三方资源权限都已经完成。

## 证据边界

- 忽略目录 `output/navigation-refresh/` 保存安全请求元数据、页面 SHA256、链接投影及本地
  归并脚本；没有保存认证材料、cookie、个人登录账号或目标站用户内容。
- `summary.json` 是实际 50 个分类页的原始批次元数据；`scoped-summary.json` 是排除通用
  分类后的最终范围与互斥计数。前者的全站链接总数不用于本报告结论。
- `current-school-entries.csv` 为 543 URL 的完整安全投影；仓库只收 277 行差异 CSV。
- 导航页成功与接口调查完成分开。OPAC、空间、CARSI、财务等实际接口证据见各业务分报告；
  本报告不会以“入口已枚举”代替“认证与业务已验证”。
