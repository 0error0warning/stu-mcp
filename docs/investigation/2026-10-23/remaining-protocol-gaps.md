日期：2026-10-23。对象仅为开源 `stu-mcp`；这是调查索引，不新增 MCP 功能、认证范围或联网目标。以下结论来自本目录已记录的请求、静态协议和当前源码，不把调查进展写成产品已经支持。

**本文件保留当时的优先级与历史对照，不是全部剩余业务清单。** 本轮补查后的完整已知
范围、精确未读项和当前阻碍以 [完整性审计](completeness-audit.md)及

## 当前支持与计数

本次只读核对 [server.py](../../../src/stu_mcp/server.py) 中 `build_server` 的 `@tool(...)` 注册定义，当前为 **47 个 MCP 工具**；[capability_catalog.py](../../../src/stu_mcp/capability_catalog.py) 的纯目录输出包含 **13 个 `implemented` 业务组、16 个未接入项**。业务组数、工具数和学校系统数不是同一口径。

现有工具覆盖通知、教务成绩与考试、MySTU/雨课堂课程活动、桑浦山宿舍设施报修、对分易、入口导航与诊断，以及第三方充电、狐友、外卖和本地维护。导航能找到入口，不代表能够办理该业务。13 个已实现组也不意味着组内所有子业务已适配。

[entry-coverage.csv](entry-coverage.csv) 的 **620 个不同原 URL** 中，176 项是业务入口或调查候选：101 项有本轮精确匿名请求，48 项仅映射到报告范围，27 项列明主模块分工或已有适配器。它们包含别名、不同路径与失败入口，不能当作 176 个系统或已验证接口。其余公开机构栏目、数据库引用、指南和排除项另列；这些分组都不证明学校业务已穷尽。

## 索引维护方式

- 以业务及精确路径维护文档级记录，分别写产品支持、协议证据、认证结果、缺少样本、最后核查时间和报告位置；最新补查覆盖结论，历史失败保留时间。
- 将独立入口、同站未适配子业务、外部资源/导航分列；新增菜单和事项关联原 URL 或公开事项 ID，不随调查自动注册来源、认证白名单或探测目标。
- 先补真实只读身份、字段、分页/空态/过期，再评估实现；申请、预约、支付、评价、改密等写入另立范围，静态接口数量不作为验收进度。

初版来自仓库文档、CSV 与纯源码定义；后续状态引用本轮分报告的实际 HTTP 请求，本索引不独立重复请求或更改运行时。调查成功、适配实现、真实 MCP 读取与目标应用导入分别验收。
