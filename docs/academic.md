# 教务成绩与考试适配

成绩与考试通过 `features/jw/` 的独立功能包读取，MCP 工具、CLI、旧 Python 导入和记录结构保持兼容。本轮只重构查询和解析，继续使用既有教务登录会话、访问策略与加密缓存。

## 代码边界

| 文件 | 职责 |
| --- | --- |
| `schema.py` | 固定查询地址/表单字段、列名及同义词、必需列、空行/统计行、主页与学期控件契约 |
| `parser.py` | 纯解析与唯一性校验；不请求网络，不读取凭据，不提交或清理缓存 |
| `adapter.py` | 在同一 HTTP 会话中读取成绩、学校选中学期和考试表；传输仍由 `CampusHTTP` 限定 |
| `service.py` | 成绩最多200条、考试按原限额、学期过滤、独立考试失败和原覆盖范围字段 |

`parsers.py` 继续导出 `parse_jw`、`jw_exam_semester`、`jw_authenticated`、`JW_COLUMNS`、`JW_SCHEMA_VERSION`；`collectors.jw(vault, limit, semester)` 继续作为兼容入口，并显式传入原 HTTP 注入点。认证和缓存内部直接引用功能包，避免依赖兼容层。包初始化不启动网络或浏览器。

## 表格变化与歧义

解析按语义列名映射，支持既有同义词、列序/空白变化、增列、`thead`/`tbody`、相同重复表头及外层布局表格。只处理选定表格自身的行，避免外层表格重复读到内层记录。表头位置变化不丢弃其前面的数据。

下列情况返回 `schema_changed`，不会猜测字段或把页面当成空结果：

- 缺少关键列；同一语义对应多个列，例如同时出现“成绩”和“总评成绩”。
- 多张表都符合完整字段，或同一张表出现不一致的表头。
- 行宽与表头不同、跨行/跨列导致映射不明确、数据单元格内嵌套业务表格。
- 课程编号或课程名缺失，记录 ID 重复，无法表示为原有唯一记录。
- 未知/错误页，或未识别出表头却只出现“暂无数据”。登录页单独返回 `login_expired`。

无记录但字段完整的表可返回空列表。独立且明确的空行、合计/平均统计行也可识别，包括合并单元格内的“合计：6学分”。课程名称里出现“合计”“暂无”等文字仍是课程数据，不能用子串匹配跳过损坏记录。表头前的合并 `th` 可作为装饰标题；未知合并 `td` 仍须通过字段/明确标记校验。

列必需与值非空是不同约束。成绩尚未公布时，`score` 可以为空或“优秀”等原文；学分/绩点无法解析或为非有限数值时仍为 `None`。考试尚未公布时间或考场时，已识别课程仍可保留空字段，不据此推断考试取消。

## 身份、学期与历史缓存

记录 ID 保持原规则：成绩使用学期、课程号、考试性质和分组；考试使用查询学期、课程号和考试时间。不同补考/分组或考试时间不按课程号合并。原 ID 无法区分的多条记录明确报错，不能静默覆盖。`JW_SCHEMA_VERSION` 保持为2，既有列映射缓存与统计口径继续有效。

没有指定学期时读取学校考试表单的实际选择，不根据本机日期猜学期；指定学期时跳过该 GET。唯一选中项旁边增加未选中的占位/未知选项不影响读取。多个控件、多个选中项、重复值或实际选中值无效时停止；没有显式选中项时沿用首个带 `value` 选项的旧规则，首项无效则报错。

成绩失败中止本次刷新，保留已存历史。考试失败保留本轮成功成绩，返回原 `考试安排` 部分失败信息，并保留旧考试记录。明确空表也不删除 JW 历史；教务不使用课程完整快照清理。旧版本缓存仍通过原版本门禁和 `unverified_count` 提醒，学业统计不会把旧错位数据当已验证成绩。

默认所有查询仍从 HTTPS 发起。`jw_http_compat` 只保留用户已明确开启的既有教务 HTTP 重定向兼容，不改为主动 HTTP 查询，不影响 SSO 或其他来源。`coverage.transport` 继续记录本轮是否经过该旧传输，包括表单中间跳转。登录证明仍只读学生主页，不下载成绩验证登录。

## 改版维护与验证

有证据的列名/标签变化优先改 `schema` / `parser`；地址或表单变化改 `adapter`；业务限额/部分失败政策才改 `service`。复杂合并结构不自动展开猜值，应先补合成样本并明确学校业务含义。正常样本必须保持字段、ID 和数值一致，歧义样本必须保留历史且避免影响独立成绩读取。

回归位于 `tests/test_jw_parser.py`、`tests/test_jw_service.py` 及既有 `test_jw_current.py` / `test_jw_compat.py`。所有本轮测试采用合成网页、注入 HTTP 和临时缓存；不包含真实成绩、会话或学校响应。真实学校联调范围仍以[验证记录](verification.md)中的历史证据为准。
