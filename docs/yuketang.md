# 雨课堂课程查询适配

雨课堂课程查询按请求运行，沿用 `refresh_source(source="yuketang")` 和既有课程、任务、资源、公告查询；`collectors.yuketang(vault, limit)` 仍是原 Python 入口。本模块属于开源 `stu-mcp`，不依赖 Hermes 私有 `school_hub`。

v0.6.0 用 `stu-mcp login yuketang` 申请官方二维码，在本人终端显示并由本人手机确认；服务端不启动浏览器。`auth_http/yuketang` 负责认证协议与学生课程正向 proof，本功能包继续负责课程业务。临时扫码原料不经 MCP/日志/文件；来源专用认证头与 Cookie 仅进入加密会话。详见[认证说明](authentication.md)。

## 分层与维护入口

| 文件（`src/stu_mcp/features/yuketang/`） | 职责 |
| --- | --- |
| `schema.py` | 已观察到的固定 API、列表字段、任务类型及每课 50 条活动/20 条公告上限 |
| `parser.py` | 纯 JSON 校验，归一化课程、活动和公告，判断库存/活动是否完整 |
| `adapter.py` | 同一雨课堂客户端内读取固定地址，交给对应解析器，不处理缓存或失败政策 |
| `service.py` | 最新原生学期、课程限额、活动与公告的独立失败边界、`CourseSync` 范围 |

功能包不反向导入 `collectors` 或旧 `parsers`，纯解析不启动网络、会话或浏览器。课程与活动使用明确的内部结果类型，现有工具继续输出原字典。

新增字段和对象键顺序变化可以兼容。课程列表使用 `data.list`、活动使用 `data.activities`、公告使用 `data.data`；已知字段改名或结构变化会明确失败，不遍历任意数组猜替代字段，也不尝试未经核验的备用 API。学校变化时，先补合成失败样本，再修改实际变化的契约/解析或访问层。

## 字段与身份

- `classroom_id` 只接受 ASCII 数字标识，保持原数字字符串；布尔、容器和重复课堂身份拒绝。非空 `course.name` 仍优先于平面 `name`，教师缺失仍为空字符串；名称与教师的异常对象不会被转换为文本。
- 最新学期仍取原生整数 `term` 最大值，`semester` 为其字符串，保留记录原 `term`。字符串学期沿用原输出，不猜测整数或标准教务学期，也不证明库存完整。布尔或容器学期属于结构错误。
- 活动类型整数 `3` / `19` 保持任务分类，其他正常整数为资源。字符串或缺失类型保留原值与资源分类，但不证明完整活动快照，避免分类漂移清掉旧任务。
- 活动稳定 ID 保持来源、类别、课堂和原活动 ID；缺失或零 ID 继续按标题回退。重复活动身份拒绝。公告必须有非空稳定 ID，避免缺 ID 的多条公告互相覆盖；重复公告身份也拒绝。
- 数字 `leaf_id` 继续组成固定练习地址，其他合法标量回课程页；保留原记录字段、可选值及 URL 语义。不从响应读取任意目标 URL。
- 未提供时间仍为 `None`；提供的布尔、对象、无效或非有限时间不伪装成正常未设置时间。结构错误只返回固定说明，不回显原始对象或提供方错误正文。

整页先验证，再按 50 / 20 条返回。即使尾行超出展示上限，其结构错误也不能被忽略来证明完整快照。

## 部分失败与缓存

| 本轮结果 | 保存/清理政策 |
| --- | --- |
| 课程库存无法解析或请求失败 | 中止本次刷新，保留原课程与活动；不继续用坏身份读下游 |
| 某课活动失败、公告成功 | 保存课程和公告；活动错误带 `course_activities` 与 `course_id`，保留该课旧任务/资源 |
| 某课活动成功、公告失败 | 保存课程和活动；公告错误带 `course_announcements` 与 `course_id`，保留旧公告及原采集时间 |
| 同课两路均失败 | 分别报告，继续下一门课程 |
| 确认完整的空活动列表 | 可以按既有 `CourseSync` 清理该课旧任务/资源，与公告是否成功无关 |
| 分页未完整、达到 50 条或分页类型不明 | 保留本页有效记录，不授权删除未出现的旧活动 |
| 库存完整且学期/课程变动 | 沿用原课程范围清理；未读取课程的活动不冒充已完整 |

外层与 `data` 层分页都会检查。声明有后页、总数大于当前页、分页字段类型不明确，都不能证明完整；明确空列表与缺字段分别处理。公告从不参与课程范围删除，空公告页也不清理历史公告。保留原 `limited=true`、覆盖范围字段、加密缓存及会话代次保护。

一次刷新只建立一个雨课堂 HTTP 客户端，先读一次库存，再对限额内每课各读一次活动与公告；不增加预检、自动翻页、重试、重新登录或后台任务。活动/公告失败不互相重试，也不扩大主机或认证范围。网络层既有业务错误与登录失效分类继续适用。

## 验证范围

本次重构使用合成 JSON、注入 HTTP、临时加密 Store 与隔离安装验证；没有读取真实账号或学校接口。正常样本的工具字段、ID、URL 与重构前比对，完整 MCP 工具定义保持一致。详细检查结果见[验证记录](verification.md)。

`yuketang_readiness` 与 `scripts/inspect_yuketang.py` 仍是独立的只读作业结构诊断，未迁入课程查询，也未新增答题或提交能力；历史真实核验范围见[校园协议核验](campus-protocols.md)。
