# v0.6.1 · 学生预览版

本版增加按需检查和单命令升级，并收录 v0.6.0 后加入的实验外卖查询。
默认 HTTP/CLI、本机 stdio 与个人服务器私有 Streamable HTTP 保持一致；继续发布为 GitHub prerelease。

## 更新入口

```sh
stu-mcp update --check
stu-mcp update
```

MCP 新增无参数的 `check_updates`、`update_self`，与 CLI 共用实现。
更新检查包含官方学生预览，不创建定时任务。推荐 uv tool 安装核实环境、发行附件与兼容性后由 uv 升级；
源码、Docker 和无法识别的环境返回对应指引。用户数据、学校凭据、外置密钥与客户端配置保留。

安装完成后核对新进程的版本；发起更新的 MCP 仍加载旧代码。stdio 需重载 MCP 以启动新进程，
私有 HTTP 需在宿主重启 MCP 服务，仅断开重连客户端无效；随后核对当前连接的运行版本。
不自动杀进程或承诺自动回滚。并发升级、其他已登记运行实例、签到后台、活动报修和下载校验失败会阻止安装。
完整行为与范围见[更新说明](../updates.md)。

## 实验外卖查询

新增 7 项 STU 外卖目录与选餐工具：查询配送区域和商家、菜单与规格、配送批次、
按实际餐段找店及生成普通标价清单。截止时间按北京时间每次重算，区分平台分类和实际配送批次，
本部与东校区不互相替代；未知与分页范围明确返回。

该来源需宿主 CLI 单独导入签名配置到现有加密 Vault，不经过 MCP 接收凭据。
当前不下单、不支付、不领券、不修改地址；清单也不代表库存、最终价格或结算可用性。
实测成功、后续失败与未验范围分别见[外卖说明](../takeout.md)及其[验证记录](../verification/2026-10-21-takeout.md)。

## 兼容与升级

- 共 47 项 MCP 工具：v0.6.0 的 38 项、7 项实验外卖与 2 项更新入口，已有工具接口保留。
- v0.6.0 还没有更新命令，首次升到本版请按[安装说明](../install.md#从旧版升级)安装本版 wheel；
  后续可直接 `stu-mcp update`。源码、容器继续按自身部署方式更新。
- 设置页、宿主 MCP 进程与独立签到后台需要分别加载新版；签到后台仍在运行或无法确认停止时阻止更新。
  新后台 health 返回 `package_version`，原 `protocol_version=1` 保持不变。技能资源按需重新导出，换解释器或机器时重新生成本机 runtime。
- 不重新初始化数据目录、密钥或账号。报修草稿和确认仅在进程内存，未知提交结果先只读恢复。
