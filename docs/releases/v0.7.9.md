# v0.7.9 学生预览版

## 本版更新

- **原生 MCP 使用指南。** `stu-campus` 通过 11 份参考文档覆盖现有 53 项工具，按任务读取外卖、医学院课表、反馈、公众号等场景的流程。既有 MCP 工具接口兼容。
- **统一发行附件。** `stu-campus-v0.7.9.zip` 包含 `SKILL.md` 和全部参考文档，可以导入支持 Skills 的 MCP 客户端，也适用于远程 Streamable HTTP。它由同一标签的 wheel 生成，安装无需本机 Python。已有 CLI Skill 导出及独立的 `stu-timetable-export` 继续使用原来的入口。
- **修复 OA 原站读取。** 校园网内的原站列表、正文及附件走匿名 HTTP，兼容旧缓存里的原站 HTTPS 链接。WebVPN 公告继续使用独立地址，保留原有会话检查与缓存保护。

## 安装与升级

已有安装运行 `stu-mcp update`，然后重载 stdio MCP 客户端，或重启自己的 Streamable HTTP 实例。首次安装可参考[安装指南](https://github.com/0error0warning/stu-mcp/blob/v0.7.9/docs/install.md)。

已连接 STU MCP 的用户可以在[同版发行页](https://github.com/0error0warning/stu-mcp/releases/tag/v0.7.9)下载 `stu-campus-v0.7.9.zip`，按[客户端接入指南](https://github.com/0error0warning/stu-mcp/blob/v0.7.9/docs/clients.md)安装。`SHA256SUMS.txt` 覆盖 wheel、源码包和 Skill ZIP。

## 验证范围

校园网复测验证了匿名 OA 通知刷新、正文读取以及附件获取后的原文交接。原站 HTTPS 链接、旧缓存及 WebVPN 路由隔离由合成回归覆盖。复测未重新验收 WebVPN 登录或受保护内容。详见 [OA 验证记录](https://github.com/0error0warning/stu-mcp/blob/v0.7.9/docs/verification/2026-10-22-oa-entry-boundaries.md#2026-11-23-校园网原站协议复测)。
