# v0.6.2 · 学生预览版

本补丁修复 GitHub 匿名 REST API 限流时无法检查更新的问题，CLI 与 MCP 工具接口保持不变。

## 修复

共享公网出口可能耗尽 GitHub 匿名 API 限额。v0.6.1 此时准确返回检查失败，但无法继续升级。
v0.6.2 只在 API 明确限流时读取同一官方仓库的 Atom 发行订阅，核对官方仓库、标签及发行校验文件中的
唯一 wheel 引用，再沿用原 SHA-256、包名、版本和 Python 兼容性检查，不需要 GitHub token。

回退结果标为 `metadata_source=github_atom`，`prerelease=null` 表示 Atom 无法证明预览标记；
不能将未知标记解释为正式稳定版。其他网络和结构错误仍如实失败。完整行为见[更新说明](../updates.md)。

## 升级

```sh
stu-mcp update
```

若当前 v0.6.1 已受 API 限流影响，请按[安装说明](../install.md#从旧版升级)手动安装本版 wheel：
先处理报修流程、停止签到后台和旧 MCP 宿主进程，再安装。正常更新命令不使用 `--force`。
stdio 重载 MCP 以启动新进程；私有 HTTP 重启宿主 MCP 服务，仅客户端重连无效。

v0.6.1 的标签、发行附件和验收记录保留原样，本补丁不扩大真实学校业务的验收范围。
