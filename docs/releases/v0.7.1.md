# v0.7.1 · 学生预览版

本版加入本人理论课表及一卡通只读查询，同时修复配置页的并发状态问题。安装文件、校验值和验证范围见本版发行记录。

## 主要变化

- **本人理论课表。** 新增 `get_academic_timetable` 和 `stu-mcp timetable`，复用 JW 独立会话，读取一个学期的理论课、周次、节次、未排课和待核对项。继续使用原课表导出技能及唯一转换器；实验课、最新校历、作息和调课另行核实，不把读取成功直接当成可完整导出。[用法](../timetable.md)
- **一卡通只读查询。** 新增 `get_campus_card` / `get_campus_card_transactions`，与 `card` / `card-transactions` CLI 共用业务核心。概况返回余额及状态，历史流水返回日期、分类和分页范围，不新增缓存、写操作或统计图。[范围](../smartcard.md)
- **独立一卡通配置。** 私密设置页和 CLI 由本人输入独立查询密码及正常图片验证码，不放进学校统一账号组，不保存查询密码或借用 SSO Cookie。官方入口使用明文 HTTP，只对此固定来源开放精确例外；普通学校/CAS 密码和 TOTP 仍为 HTTPS。不使用 OCR、模型、验证码绕过或浏览器回退。
- **配置并发修复。** 复用 WebVPN 短锁，避免 Windows 状态轮询与标记文件替换冲突；设置页先取任务快照再读取账号状态，避免混合旧状态与新完成任务。没有增加认证重试。
- **校园协议维护。** 收录按业务整理的入口、认证与只读字段证据；调查记录与实际接入分别标注，不将发现入口算成已实现功能。

相对 v0.7.0 原 47 项工具，新增课表及两项一卡通工具，合计 **50 项**；课表阶段已有的 48 项完整定义在本轮逐项保持一致。原 `get_courses`、短期 `get_schedule`、报修确认和单次提交行为保持兼容。

## 安装与升级

安装：

```sh
uv tool install --python 3.12 https://github.com/0error0warning/stu-mcp/releases/download/v0.7.1/stu_mcp-0.7.1-py3-none-any.whl
```

已有受支持的 uv tool 安装可运行 `stu-mcp update`；手动升级及源码/容器使用方式见[安装说明](../install.md)。stdio 需重载 MCP，私有 HTTP 需重启宿主 MCP 服务；只重连客户端不会加载新代码。关闭旧设置页后重开。对分易后台若仍在运行，先暂停并退出，再更新并按需恢复；配置、会话与用户数据保留。

学校统一账号配置不自动登录一卡通。需要时在自己的私密设置页配置，或运行 `stu-mcp login smartcard`；无桌面真实终端可以看图填写验证码。登录数据、验证码和明文 HTTP 会话不得转交 agent 或发布到 issue。
