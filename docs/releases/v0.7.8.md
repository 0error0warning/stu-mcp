# v0.7.8 附件交接与 DSH 兼容

本版根据 DeepSeek 的公开思考文本和实际 MCP 调用修正附件交接，扩大有界查询数量，并发布 DSH 插件0.1.1，继续作为学生预览版提供。

## 本次变化

- **验证码后结束当前附件获取。** `handoff_required=true` 时立即给出通知标题、原文链接及未读说明，不能为凑齐条款继续重试下载、遍历缓存、刷新 OA 或借其他工具获取全文。用户要求总结条款不等于明确要求寻找替代版本；已有明确替代检索要求时仍可继续。建议用户提供正文的行为不受新增限制。
- **缓存查询和来源刷新最多100条。** 从50提高到100，默认20条不变。实际校验、错误消息及 MCP Schema 同步，101条仍返回结构化参数错误。原有来源页数和请求预算不变，实际范围继续看 `coverage`、`limited`、`errors`；允许100条不代表每个上游都能返回100条。
- **公开来源不预设网络条件。** 公开详情及附件交接返回 `source_access.login_required=false`、`user_network_checked=false`，避免把学校域名理解为必须校园网或 WebVPN。OA 不继承公开访问标记，保留其原有访问和注销保护。
- **DSH 插件0.1.1。** 明确支持 DSH 0.2.1-rc.3及0.2.2-rc.3，沿用共同 MCP、状态和设置入口；没有独立业务实现或模型配置。
- **文件凭据后端首次并发初始化。** 发行 CI 暴露了 Windows 下锁文件在取得锁之前被写入的旧竞争问题。现在取得锁后才初始化，并使用无缓冲的锁文件句柄，避免失败写入在关闭时重放；加密映射和默认系统密钥库不变。新回归用另一进程持有空锁文件，验证等待后写入，而非抢先写入或失败。

仍为53项工具，既有参数、默认值、输出 Schema 和工具注解保持兼容。报修预览/本人确认/单次提交、来源会话隔离和签到后台规则保持原样。本版不包含另行维护的教务/MySTU 协议草稿。

## 使用与验证范围

验证码后的交接规则同时进入服务说明、工具说明、结果及随包技能。此前真实公开页面对照中，官方0.7.7用了63次 MCP 调用，候选两轮各4次；用户反馈后的修订候选也在4次后停止。100条缓存请求直接成功。这些是同一模型和任务的小样本观察，不能保证其他模型或提示词有相同调用次数。

开发阶段的完整工作区回归包含其他协议草稿，其数量不作为本版数量；准确发布提交的全量测试、隔离安装、发行包和跨平台检查见[发行页](https://github.com/0error0warning/stu-mcp/releases/tag/v0.7.8)。历史阶段、用户取舍及原始数据的保存范围见[思考日志复测](../verification/2026-11-15-dsh-thinking-study.md)和[本机 DSH 验证](../verification/2026-11-15-dsh-local.md)。

## 安装与升级

已有安装运行 `stu-mcp update`。首次安装：

```sh
uv tool install --python 3.12 https://github.com/0error0warning/stu-mcp/releases/download/v0.7.8/stu_mcp-0.7.8-py3-none-any.whl
```

升级后重新加载 stdio MCP；个人 HTTP 实例需重启宿主服务。DSH 0.2.2 用户安装或更新本次附件 `dsh-stu-mcp-0.1.1.tgz`，命令见[插件说明](../../integrations/dsh/README.md)。核心包和可选侧栏插件分别安装；已有0.1.1本地兼容构建的业务实现未改变。

发行附件为 wheel、源码包、DSH 插件包和 `SHA256SUMS.txt`。本次发布不自动改写用户当前已安装的核心包或客户端配置。
