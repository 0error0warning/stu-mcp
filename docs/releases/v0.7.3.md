# v0.7.3 · 反馈隐私与用户同意（学生预览版）

修正 v0.7.2 的反馈外发流程：Agent 可以起草报告，但发送前必须完整展示准确内容、接收方、
用途及存储说明，等待本轮用户明确同意。首次 `report_feedback` 只本地预览，不联网；
第二次需使用匹配的预览标识及确认参数。内容或接收方改变、预览过期后须重新征求同意。
确认标识在发送前消费，未知回执不自动重试。用户拒绝不影响原任务。

优先使用错误码、复现步骤、脱敏或合成示例。个人业务信息只有确实必要且用户逐项同意时，
才允许最小片段；密码、Cookie、token、验证码、密钥和登录回调始终禁止发送。
存储、IP 可见性及 Agent 对真实用户答复的责任见[完整隐私说明](../feedback.md)。

服务端拒绝缺少该流程的旧官方客户端（低于 0.7.3）。版本和确认标志不能证明真实同意；
Agent/客户端不得自行授权或把未回复、过去的同意当作本次同意。

```sh
stu-mcp update
```

更新后重载 MCP；HTTP 实例需重启宿主服务。保持 51 项工具，校园读取和既有数据不变。
本版继续通过 GitHub 学生预览发行，附件为 wheel、sdist、SHA256SUMS.txt；未发布到 PyPI。
