# v0.7.5 充电设备位置修正

本版按用户提供的设备二维码照片修正充电设备清单和位置查询，继续以学生预览版发布。

- 补入教师宿舍 `4GR00006723`，清单现有 15 台设备。
- 修远书院对应 `4GR00008480`；平台登记名仍为“明德书院 MD-1”，另外保存在 `provider_name`。
- 思源左一至左四分别对应 `SY-4`、`SY-3`、`SY-2`、`SY-1`；滑板场一、二分别对应 `YDC-2`、`YDC-1`。
- 补齐文科教学楼、图书馆中文序号及文档用名的查询。原有平台名称、编号和别名仍可使用。

文档中的 14 台均通过公开设备信息核对，并各取得完整的 20 口状态。原清单中的水电中心另行保留，本次报告离线；清单仍不代表全校完整覆盖。请求签名、协议和只读接口范围保持原有实现。

完整对应表见[位置核对记录](../verification/2026-10-29-charging-locations.md)。

## 安装与更新

已有安装运行：

```sh
stu-mcp update
```

首次安装：

```sh
uv tool install --python 3.12 https://github.com/0error0warning/stu-mcp/releases/download/v0.7.5/stu_mcp-0.7.5-py3-none-any.whl
```

升级后重新加载 stdio MCP；个人 HTTP 实例需重启宿主服务。DSH 薄插件仍为 `0.1.0`，已有插件无需重装，重新加载其 MCP 连接即可使用新版核心。

## 验证

充电及 MCP 相关检查 173 项通过；Windows 全量测试 2592 项通过、4 项跳过，Ruff 检查通过。包含文档全部 14 个位置、教师宿舍单台查询、修远与平台原名区分，以及真实 stdio MCP 调用。旧清单的 53 种已有查询写法仍对应相同设备编号。

发行附件提供 Python wheel、源码包、未改动的 DSH 插件包和 `SHA256SUMS.txt`。安装包、跨平台 CI 与公开下载验证以本次发行验收结果为准。
