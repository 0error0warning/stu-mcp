# v0.7.4 · DSH 插件与公众号阅读（学生预览版）

DeepSeek Harness 现在可以安装 STU MCP 插件，在侧栏查看账号状态并打开登录设置。
常用功能每项只显示一行用途；其他功能和连接信息默认折叠。
插件继续调用同一个 MCP，其他 agent、CLI 和个人服务器使用共同业务与认证实现。

本版共 **52 项 MCP 工具**。新增免登录公众号文章读取 `get_wechat_article`：
提供已知公开文章链接即可读正文，默认使用匿名 HTTP；可显式选择独立无头浏览器。
验证、限流、删除、正文不足和网络错误分别返回状态，不接入公众号搜索、订阅或私聊。

同时增加 `connect dsh --profile` 与通用 `verify`，并修复学生处通知正文和附件识别。
已有工具接口和配置合并行为保持兼容。

## 安装与更新

已有安装运行：

```sh
stu-mcp update
```

首次安装：

```sh
uv tool install --python 3.12 https://github.com/0error0warning/stu-mcp/releases/download/v0.7.4/stu_mcp-0.7.4-py3-none-any.whl
```

升级后重载 stdio MCP；HTTP 实例需在宿主重启服务。需要时重新运行当前 agent 的接入命令。
DSH 用户先运行 `stu-mcp connect dsh --apply`，再下载发行附件 `dsh-stu-mcp-0.1.0.tgz`。
使用桌面安装随附的 CLI 安装该文件，例如 Windows：

```powershell
& '<DSH 安装目录>/resources/runtime/cli/bin/dsh.cmd' plugin --profile desktop add '<下载目录>/dsh-stu-mcp-0.1.0.tgz'
```

重启 DSH 后，左侧 **STU MCP** 或右侧同名标签均可打开面板。
当前插件支持经过实测的 DSH **0.2.1-rc.3**；发行附件可直接安装，无需源码构建。
GitHub 发行与 DSH 公共插件市场分开管理，本版尚未上架公共插件市场。
