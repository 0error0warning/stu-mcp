# v0.7.6 医学院课表协议接入

本版迁入医学院教务本地口令认证和当前学期课表解析，继续以学生预览版发布。

- 新增独立「医学院教务」设置、`login med_jw`、`timetable --source med_jw` 与 `get_medical_timetable`。原 52 项 MCP 工具定义保持兼容，合计 53 项。
- 复用现有 HTTP、人工验证码、Vault、取消和注销保护；只保存独立加密业务令牌，不保存普通口令。
- 严格区分空课表、坏响应与部分漏读，保留学校原生学期信息；不猜主校区校历，不写手动课表或课程缓存。
- APP 数据库、路由、定时同步和界面未迁入。医学院 SSO、成绩、考试与历史学期不在本版范围。

**医学院能力尚待真实账号验收。** 本次验证使用合成账号及模拟学校响应，没有进行真实校园登录。使用方法和实现边界见[医学院教务课表](../medical-jw.md)。

## 安装与更新

已有安装运行 `stu-mcp update`。首次安装：

```sh
uv tool install --python 3.12 https://github.com/0error0warning/stu-mcp/releases/download/v0.7.6/stu_mcp-0.7.6-py3-none-any.whl
```

升级后重新加载 stdio MCP；个人 HTTP 实例需重启宿主服务。DSH 薄插件仍为 `0.1.0`，已有插件无需重装。

发行附件包含 wheel、源码包、未改动的 DSH 插件包和 `SHA256SUMS.txt`。测试与安装包验证结果见发行页。
