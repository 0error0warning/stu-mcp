# v0.7.2 · Agent 反馈（学生预览版）

新增 `report_feedback`，agent 可以把具体工具故障、疑似数据错误和改进建议提交给维护者。
工具总数为 51，既有 50 项接口保持兼容。

反馈接收端已经上线，默认地址为 `https://stu-mcp.com/api/feedback`。用户无需配置服务器、
数据库、GitHub 授权或 Tailscale；只需能够访问该 HTTPS 地址。反馈保存于服务器独立 SQLite。

提交只包含显式描述、工具名、类别、软件版本和随机报告编号。不自动附带聊天、日志、
校园数据或账号信息；描述也应脱敏。存在常见凭据粘贴检测、长度和频率限制，但这不是
完整的个人信息检测。反馈属于待核实线索，不会自动修改校园数据。超时可能表示送达状态
未知，不自动重试，反馈失败不影响其他校园工具。

## 更新

已有支持更新命令的 uv tool 安装：

```sh
stu-mcp update
```

更新后重载 stdio MCP；个人服务器上的 HTTP 实例需要重启宿主服务，再核对版本。
全新安装或旧版按[安装说明](../install.md)操作：

```sh
uv tool install --python 3.12 https://github.com/0error0warning/stu-mcp/releases/download/v0.7.2/stu_mcp-0.7.2-py3-none-any.whl
```

当前仍通过本仓库 GitHub 学生预览版发行，未发布到 PyPI。发行附件为 wheel、sdist 和
`SHA256SUMS.txt`。安装和更新会保留原有配置与用户数据，活动签到/报修等仍遵守既有更新保护。
