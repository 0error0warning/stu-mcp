# v0.7.7 校团委与 Agent 使用体验

本版将校团委8个公开栏目接入原有 `public` 来源，并完善全部53个工具的调用衔接，继续以学生预览版发布。

## 校团委读取

支持通知公告、团学动态、挑战杯、中国国际大学生创新大赛、攀登计划、规章制度、办事流程和资料下载。列表解析分栏日期与摘要，正文识别两种已观察容器及正文外的附件列表。每栏目最多读3页，沿原站倒序“下页”链接继续；翻页失败保留已读内容，并分别报告栏目覆盖。

公开读取无需新增登录。真实匿名读取和下载验证码的观察日期为2026-11-15，见[专项记录](../verification/2026-11-15-xtw.md)；这不代表所有历史栏目或附件均已读完。附件遇验证码、扫描或空 PDF、不支持格式及已识别的错误网页时，明确返回未读状态和通知正文链接，供用户在原网页自行查看。

## Agent 调用变化

- `get_capabilities(source="public", compact=true)` 按来源返回精简状态。原来的无参数调用仍返回完整目录，保存会话不代表实时业务可用。
- 通知搜索返回至多1200字符的正文预览及 `detail_call`；`get_notice` 默认每页8000字符，最多20000字符。**需要完整正文的调用方应沿 `next_offset` 或 `next_call` 续读**，续页使用 `refresh=false`。完整缓存和全文检索保留。
- `metadata_only`、`attachment_not_cached`、`no_attachments` 和 `invalid_attachment_index` 分别说明正文/附件所处阶段，避免重复刷新。`show_source_link` 让 agent 将原文链接交给用户，不索要验证码或安排验证后续调。
- 空查询给出范围、原因和下一步调用；多来源查询优先使用免登录或已配置来源。分页补充 `next_offset`，受限统计不当成完整结果。
- `set_student_profile` 只修改非空的已提供字段，其他字段保留；明确清空使用 `clear_fields`。空字符串现在保留原值。
- 远程缺登录返回本人在 MCP 宿主执行的命令；stdio 与 HTTP 的重启动作分别说明。固定参数选项进入工具 Schema，外卖餐段歧义返回实际分类/区域和有界继续调用。

工具名称、既有参数类型/默认值/必填项、输出 Schema 和 annotations 保留；新参数均可选。正常使用登录验证码的独立一卡通/医学院认证仍由本人在私密设置页或终端完成。报修的完整预览、本人确认及单次提交约束继续适用。

具体字段和 CLI 示例见[调用约定](../agent-usage.md)；开发阶段的检查范围与失败恢复见[Agent 检查记录](../verification/2026-11-15-agent-usability.md)。本版未包含工作区中另行维护的教务/MySTU 协议补丁或预约调查草稿。

## 安装与更新

已有安装运行 `stu-mcp update`。首次安装：

```sh
uv tool install --python 3.12 https://github.com/0error0warning/stu-mcp/releases/download/v0.7.7/stu_mcp-0.7.7-py3-none-any.whl
```

升级后重新加载 stdio MCP；个人 HTTP 实例需重启宿主服务。DSH 薄插件仍为 `0.1.0`，已有插件无需重装。

发行附件包含 wheel、源码包、未改动的 DSH 插件包和 `SHA256SUMS.txt`。本版准确提交的全量测试、隔离安装、跨平台 CI 和公开下载校验结果记录在[发行页](https://github.com/0error0warning/stu-mcp/releases/tag/v0.7.7)，不将此前包含其他本地草稿的测试数量当作本版数量。
