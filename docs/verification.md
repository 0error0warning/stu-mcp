## 本机工程验证

- 真实 stdio 子进程握手、工具发现、结构化返回与按来源登录限制。
- 密钥库失败、加密会话/个人缓存、首次密钥并发创建、退出隔离、重新登录清缓存。
- 退出期间刷新结果不能重新写入个人缓存，来源变化会报告 `session_changed`。
- 目的地址、重定向、认证 cookie 范围、过期 cookie、响应大小/请求数量/读取时间上限。
- 教务 HTTP 兼容默认关闭、仅教务主机可开启、密码 HTTP 提交拦截、Secure cookie 与统一认证 cookie 隔离。
- 压缩响应只解码一次；解析失败不会报告成没有成绩/通知。
- 客户端配置保留、备份、幂等、损坏配置和同名冲突保护。
- 本地设置页 Host/Origin/能力令牌保护、参数限制与 CSP。
- 浏览器首次按需准备的调用路径，以及下载失败时不保存登录态。
- Windows 实际安装了 Playwright Chromium；设置页通过真实 Edge 检查桌面/手机布局、保存接入和通用配置导出。使用隔离测试目录，未写开发者真实客户端配置。
- wheel 构建包含本地 UI 资源，不包含环境文件、数据库、登录态或浏览器测试记录。
- 隔离用户工具目录从 wheel 安装成功，生成的 MCP 命令指向工具自身的 Python；真实 stdio 握手发现 16 个工具，读取匿名 OA 缓存成功。
- 发行包匿名实测：官网栏目与服务入口共保存 55 条，OA 列表保存 5 条，均无来源错误；`partial` 表示限定读取范围。

Windows 主机无法创建符号链接时，真实符号链接测试会跳过；CI 的 Linux/macOS 会运行该测试。跨平台 CI 结果以 GitHub Actions 为准，不将本机通过当作其他系统已通过。

## 0.3.0 可选 WebVPN 自动重登

已经核对学校当前官方 HTTPS 登录页的账号输入、隐藏的同意声明复选框和公开脚本，不提交真实账号或动态码。[学校 WebVPN 使用指南](https://webvpn.stu.edu.cn/com/help.html#9) 是用户完成令牌绑定的入口；自动流程不进行绑定。TOTP 使用 [PyOTP](https://pyauth.github.io/pyotp/) 的标准算法，测试使用 RFC 6238 公布的合成向量。

新增验证覆盖：系统密钥库存储且不回显凭据、密钥格式校验、真实 HTTP 客户端对失效状态的识别、受保护列表/正文/附件的会话恢复、匿名 OA 不触及凭据、一次认证与尝试间隔、拒绝凭据/人工验证暂停、退出/配置替换/移除的并发隔离、保存会话和写缓存之间退出时不恢复旧数据、密钥库删除失败后先关闭自动重登并支持再次移除。测试只使用合成账号、会话和页面。

真实 Chromium 在完全拦截的合成学校页面上验证了账号密码和新生成动态码各提交一次、隐藏同意框操作、验证码/令牌绑定暂停及跨站 POST 拦截；没有发出真实学校认证请求。真实 Edge 在隔离目录与内存密钥库上验证了可选表单的保存、输入清空、不回填和凭据移除，桌面/手机布局无横向溢出，控制台无错误。

真实学生账号下的令牌参数、会话失效后的重登、HTTPS OA 代理可用性仍待验收，不能用工程测试替代这一结论。无定时保活或后台 AI。CI 覆盖平台见 GitHub Actions。

Windows 本机完整验证为 134 项通过、1 项真实符号链接测试跳过，代码检查与 Skill 格式检查通过。0.3.0 wheel 在隔离的用户工具目录安装成功，stdio 仍发现 16 个工具；公开读取保存 55 条，匿名 OA 保存 5 条，来源错误列表为空，限定范围标记为 `partial`。
