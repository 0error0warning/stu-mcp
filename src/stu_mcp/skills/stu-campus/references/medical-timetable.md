# 医学院课表

1. 查看 `med_jw` 的配置与登录指引。调用 `get_medical_timetable()` 读取本人当前学期课表，工具无参数。使用独立的医学院教务会话。任意历史学期、成绩与考试超出此工具范围。
2. 缺登录时按返回的 `next_action` 处理。支持私密设置页的本机实例可用 `open_setup`，由用户选择「医学院教务」并输入教务本地口令、填写学校图片验证码。远程返回 `login_on_host_cli` 时，把 `host_command` 给用户，让本人在 MCP 宿主完成配置。医学院教务本地口令和统一认证密码可能不同。
3. 登录后重新读取。沿用响应中的原生学期、周次、节次与日期，遇到 `pending` 或 `coverage.complete=false` 时说明部分结果。读取失败或缺登录时报告对应状态。适配器目前通过合成测试，尚待真实医学院账号验收；需要展开为日历日期时另外核对医学院对应校历、作息及调课，保留未确认项。
