# 微信公众号文章读取

1. 使用 `get_wechat_article` 读取已知文章链接。输入为 HTTPS 的 `mp.weixin.qq.com/s/...` 短链，或含 `__biz`、`mid`、`idx`、`sn` 的公开长链。需要用户提供文章时，请其给出公开原文链接，省去登录参数。
2. 默认用 `backend="http"` 匿名读取。需要正常页面渲染时可显式选 `backend="browser"`，由 MCP 宿主用已有可选 Chromium 依赖创建全新匿名无头上下文。浏览器路径不借用本人浏览器、Cookie 或微信登录态。HTTP 失败按结果处理，遇到验证或限流时不切换后端反复尝试。
3. 依据 `content_ready` 确认是否读到正文。`has_more=true` 时按 `next_offset` 续读，默认每页 8000 字符。续页重新读取原文，若正文变动，避免把不同版本拼成一篇。公众号显示名仅作为来源标签，正文覆盖范围为文字，图片、媒体和评论另行说明。
4. 遇到 `next_action="show_source_link"`，将可点击的 `source_url` 交给用户自行查看。保留验证码、失效、限流、网络错误或结构变化的实际状态，既不向用户索取验证码，也不把标题、摘要或错误页写成全文。
