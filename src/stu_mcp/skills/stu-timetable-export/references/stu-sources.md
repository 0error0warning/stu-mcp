# 学校来源、最新校历与访问

这些是发现入口，不是固定学期的数据副本。目录/文档入口于2026-10-20核对；每次制作重新读取目标学期相关页面，记录实际访问时间。附件地址从本次发布页提取，不固定历史 hash。

| 角色 | 官方入口 | 读取要点 |
| --- | --- | --- |
| 校历目录 | https://jwc.stu.edu.cn/wdxz/jxxl.htm | 按目标学年筛选，核对发布日期/修订/更正和原附件；列表排序不是业务有效性证明 |
| 教务办公通知 | https://jwc.stu.edu.cn/jxdt/bgtz.htm | 与目标学期直接相关的公开校历更正、作息或教学安排；不等于 OA 全部通知 |
| 学校学期制度 | https://jwc.stu.edu.cn/info/1099/3387.htm | 2026-06-02发布、自2026秋实施的制度是历史已核对事实；后续运行仍需检查目标学期是否有更正，不把其周次直接当课表周次 |
| 作息发现 | 校历目录中的“课堂作息时间表”及校区当前正式通知 | 目录仍挂旧文不代表适用所有校区/对象，按正文和有效日期确认，不把旧节次时刻写入默认值 |
| OA | 开源 STU MCP 已配置的 OA 来源 | 仅用户明确开启后通过该来源访问；使用其原网络/认证边界，不把其他系统或私有服务当替代 |
| 本人理论课表 | `get_academic_timetable`；学校来源为 https://jw.stu.edu.cn/jsxsd/xskb/xskb_list.do | 返回当前或指定学期的全部周次及真实学期选项；核对未排课和待核实项，实验课与校历另行取证 |

“最新”指目标学期最新有效的官方版本。流程：重新读目录 → 确定目标学期条目及可能修订 → 读正文与原附件 → 核对适用对象和明确替代关系 → 记录版本/链接/核查时间。若目标学期尚未发布，询问或返回未发布；不拿前一学期日期替代。未来学年的新发布也不能替换用户指定的历史学年。

记录来源标题、发布单位、发布时间、适用学期/校区/对象、链接、核查时间，以及相关页码/图中位置或简短条款依据；附件可记录摘要以识别后续变化。图片/PDF需实际读取，不把图片链接存在等同于读到日期。

## 现有开源工具可做什么

- `get_academic_timetable(semester="…")`：按需读取本人理论课表，不需要先刷新成绩。CLI 对应 `stu-mcp timetable --semester …`；省略学期时读取学校表单实际选中项，不能用它替换用户已指定的学期。返回的 `courses` 与转换器课程结构兼容，按[输入映射](reviewed-input.md#从教务读取结果组装)组装，不能把整段查询结果直接当已核对输入。
- `get_courses`：MySTU/雨课堂最新可用学期课程库存，不是周次课表。
- `get_schedule`：MySTU过去7天至未来31天的个人日程，不是全学期。
- OA开启后可按需 `refresh_source(source="oa", limit=...)`、`search_notices(source="oa", query=...)`，用命中的 `item_id` 调用 `get_notice(refresh=true)` / `read_attachment`。CLI对应 `refresh oa`、`query notice --source oa --search ...`、`notice ID --refresh`、`attachment ID --index N`。
- 通知搜索只搜本地缓存；当前列表刷新有限额，空结果不能证明全学期没有通知。报告真实覆盖范围，不声称存在尚未实现的 OA 全站远程搜索。
- `read_attachment` 仅支持既有 PDF/文本提取，扫描件不自动 OCR；JPG 校历要使用可用的只读浏览/图片工具查看。没有这些能力就说明缺口。

旧版尚无该工具，或需要实验课等未覆盖范围时，技能仍可处理用户已有的完整课表文件。不得猜测教务URL/参数或用课程名合并不同来源教学班。用户授权的真实页面/课表不保存为仓库测试样本。

网络与认证复用原访问路径：校园站点先用适用直连，OA受保护读取沿用可选 WebVPN。连接失败与“无通知”分开；不自动改代理、DNS或证书设置，不保存ticket为稳定链接。凭据由本机设置和官方页面管理。

OA默认关闭仅影响主动OA查询。已取得的公开教学通知和用户主动提供的相关规则仍按其范围处理；不能借此隐藏已知矛盾，也不能把引用OA原文当作自动开启OA的授权。
