# WakeUp 官方入口与导入边界

官方入口于2026-10-20核对。实际制作时按用户系统/版本重新阅读文档和模板，页面没有绑定版本时不能自行补一个兼容版本。

- 指南根入口：https://www.wakeup.fun/doc/
- 导入总览：https://www.wakeup.fun/doc/import_schedule.html
- CSV说明与原模板链接：https://www.wakeup.fun/doc/import_from_csv.html
- 课表设置：https://www.wakeup.fun/doc/settings/schedule_settings.html
- 高级功能/平台差异：https://www.wakeup.fun/doc/settings/advance_features.html

从CSV说明页取得当前官方模板，不复用第三方JSON或猜原生备份格式。本次确认的CSV列顺序是 `课程名称,星期,开始节数,结束节数,老师,地点,周数`；星期为1–7，节次为数字，间断周按官方顿号语法表达。未知老师/地点按当前模板填“无”，其他必需字段不填假值。编码、CSV引号和换行交给脚本处理，不能改文件后缀假装完成转换。

CSV课程数据没有包含完整学期设置。另给用户明确的教学周基准日期、学期周数、一天节数和实际节次时间；应用中“学期开始日期”的设置必须能与课表周次对齐。使用脚本的 `wakeup-settings.json`，不要假设App默认作息或默认当前周正确。

先展开实际课次，再检查能否投影为该学期的周次/星期/节次。特殊日期、超出周数、无法表达的时间或同名不同班的歧义不能静默丢弃；查看该目标的报告。无法无损表达时交付失败原因或可用的其他格式，不能声称CSV已覆盖全部特殊规则。

导入步骤按用户当前系统读取官方说明。总览、CSV、分享备份与高级功能是不同路径；页面或实际App能力冲突时以核验结果说明，不能把某平台能力直接套给其他平台。未导入真实App时只称“已生成并校验文件”，不称已完成WakeUp导入。
